## 一、时间戳

### 用法
```python
from datetime import datetime

timestamp = datetime.now()               # 获取当前时间对象
formatted = f"{datetime.now():%H:%M:%S}" # 直接在 f-string 里格式化
```

### 常用格式符
| 符号 | 含义 | 示例 |
|------|------|------|
| `%H` | 24小时制小时 | 14 |
| `%M` | 分钟 | 05 |
| `%S` | 秒 | 09 |
| `%Y` | 四位年份 | 2025 |
| `%m` | 月份 | 08 |
| `%d` | 日 | 17 |

### 在项目中的使用
```python
clipboard_text.insertItem(0, f'[{datetime.now():%H:%M:%S}] {preview}')
```
在每条历史记录前加上时间戳，方便查看复制的时间。

## 二、系统托盘（QSystemTrayIcon）

### 核心概念
托盘是 Windows 右下角的图标区域。程序"关闭"时实际上只是**隐藏窗口**，图标留在托盘里继续后台运行。

### 基本结构
```python
from PySide6.QtWidgets import QSystemTrayIcon, QMenu
from PySide6.QtGui import QIcon

# 1. 创建托盘图标
tray = QSystemTrayIcon(parent_widget)
tray.setIcon(QIcon("app.ico"))
tray.setVisible(True)
tray.setToolTip("悬浮在图标上显示的提示文字")

# 2. 创建右键菜单
menu = QMenu()
action_show = menu.addAction("显示窗口")
action_quit = menu.addAction("退出")
action_show.triggered.connect(window.show)
action_quit.triggered.connect(app.quit)
tray.setContextMenu(menu)

# 3. 弹出气泡通知
tray.showMessage("标题", "内容", QSystemTrayIcon.MessageIcon.Information, 2000)
```

### 拦截关闭事件
```python
def close_to_tray(event):
    event.ignore()   # 不真正关闭
    window.hide()    # 只是隐藏
    tray.showMessage("提示", "已最小化到托盘", QSystemTrayIcon.MessageIcon.Information, 2000)

window.closeEvent = close_to_tray
```

> **关键点**：`event.ignore()` 必须写，否则窗口仍会关闭。

## 三、悬浮球

### 无边框 + 置顶 + 透明背景
```python
ball = QWidget()
ball.setWindowFlags(
    Qt.WindowType.FramelessWindowHint |    # 无边框
    Qt.WindowType.WindowStaysOnTopHint |   # 始终置顶
    Qt.WindowType.Tool                     # 不在任务栏显示
)
ball.setAttribute(Qt.WidgetAttribute.WA_TranslucentBackground)  # 背景透明
```

| Flag | 作用 |
|------|------|
| `FramelessWindowHint` | 去掉标题栏和边框 |
| `WindowStaysOnTopHint` | 永远浮在其他窗口上面 |
| `Tool` | 不出现在任务栏 |
| `WA_TranslucentBackground` | 窗口本身透明，圆角靠 border-radius 实现 |

### 可拖拽移动
```python
drag_pos = None

def ball_mouse_press(event):
    global drag_pos
    if event.button() == Qt.MouseButton.LeftButton:
        # 鼠标在屏幕上的位置 - 窗口左上角在屏幕上的位置 = 鼠标在窗口内的偏移
        drag_pos = event.globalPosition().toPoint() - ball.frameGeometry().topLeft()

def ball_mouse_move(event):
    global drag_pos
    if drag_pos and event.buttons() == Qt.MouseButton.LeftButton:
        # 新窗口位置 = 鼠标屏幕位置 - 偏移量
        ball.move(event.globalPosition().toPoint() - drag_pos)

def ball_mouse_release(event):
    global drag_pos
    drag_pos = None

ball.mousePressEvent = ball_mouse_press
ball.mouseMoveEvent = ball_mouse_move
ball.mouseReleaseEvent = ball_mouse_release
```

## 四、关于"监听"的本质理解

你的理解很准确：

> **所谓监听，本质上是"以操作或时间为触发，执行数据提取"的操作组合。**

具体到这个项目：

```
QTimer 每 500ms 触发一次
    → 执行 check_clipboard()
        → 读取剪贴板当前内容
            → 与上次对比，不同则记录
```

这就是"轮询监听"。本质是：**定时器 + 条件判断 + 数据操作**，没有神秘之处。

另一种方式是"事件监听"——Qt 本身提供了 `QClipboard.dataChanged` 信号：
```python
clipboard.dataChanged.connect(check_clipboard)  # 内容变化时自动触发
```
这比 QTimer 更高效，但原理相同：都是**触发 → 响应**。
